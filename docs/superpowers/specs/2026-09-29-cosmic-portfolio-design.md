# Cosmic Portfolio Redesign

## Goal

「れふれふ」がShaderとリアルタイムVFXを探究している個人であることを、作品そのものに近い空気感で伝える。サイトは黒を基調に、紫・青・ごく少量の白い発光を使い、宇宙的でありながら静かで洗練された印象にする。

参考として受け取った `Cosmo_effects.png` は、色・光・モチーフを理解するためだけに使用する。画像ファイル自体、切り抜き、トレース、加工物はサイトへ収録しない。星粒、星座線、流星、ネビュラはブラウザ上で独自に生成する。

## Audience and success criteria

主な閲覧者は、作者の活動を初めて知る人、作品を見たい人、連絡先を探している人とする。

成功条件:

- 最初の数秒で「Shader / VFXを作る人」と分かる。
- 宇宙的な発光表現が印象に残る一方、本文と導線を邪魔しない。
- 実務経験を誇張せず、探究・制作中の個人として自然に見える。
- Profile、Works、Contactへ迷わず移動できる。
- PCとスマートフォンの両方で読みやすく、動きを減らすOS設定にも対応する。
- GitHub Pagesで追加のビルド工程なしに配信できる。

## Information architecture

公開ナビゲーションは次の3項目だけにする。

1. `PROFILE` — `index.html`
2. `WORKS` — `works.html`
3. `CONTACT` — `contact.html`

既存の `about.html` は旧URLを壊さないため、`index.html` へ誘導する軽量な互換ページにする。ナビゲーションには表示しない。

本文は日本語を基本とし、ページ名、短いラベル、作品種別などに英語を使う。

## Visual system

デザイン方向は **Silent Cosmos** とする。

- 背景色はほぼ黒の `#050509`。真っ黒一色ではなく、ごく薄い青紫の階調を加える。
- 主な発光色は violet、electric blue、ice blue。黄色やピンクはアクセントとして少量だけ使う。
- 余白を広く取り、境界線は細く、角丸は控えめにする。
- 大見出しは端正なサンセリフ、補助情報は等幅フォントで組み、アーティスト性と技術性を両立する。
- 写真素材を背景に敷かず、CSSとCanvasの生成表現を使う。
- すべてのページにページ番号、セクション名、小さな座標風ラベルを置き、作品集としての統一感を出す。

## Motion and generated effects

共通背景を担う `assets/js/cosmic-field.js` を新設し、既存の海中表現 `ocean-bg.js` を置き換える。

背景Canvasでは以下を生成する。

- 密度を抑えた星粒。緩やかに明滅し、奥行き別にわずかに移動する。
- 数点を結ぶ細い星座線。常時大量に表示せず、ゆっくり現れて消える。
- 画面端の淡いネビュラ。低彩度・低不透明度で本文の背後を避ける。
- 稀に横切る短い流星。高頻度にはしない。
- ポインター周辺のごく弱いパララックス。クリック演出は設けない。

ページ遷移時はCSSによる短いフェードとスライドだけを使う。ホバーでは線や文字の輝度を少し上げ、強い拡大や連続するフラッシュは使わない。

`prefers-reduced-motion: reduce` ではCanvasを静止状態にし、遷移・ホバーアニメーションをほぼ無効にする。Canvasを利用できない環境でも、CSS背景だけで内容を読めるようにする。

## Page design

### Profile / `index.html`

ファーストビューは左寄せの大きな「れふれふ」、英字表記 `LEFLEF`、肩書き `Shader / VFX Explorer` で構成する。右側には画像ではなく、Canvasで生成する静かな軌道リングと星粒の焦点を置く。

スクロール後に短い自己紹介と現在の関心領域を表示する。内容はShader、Realtime VFX、Unity、表現研究に限定し、職歴や受注実績を示す文言は使わない。

### Works / `works.html`

作品一覧は大きめのカードによる一列または二列グリッドにする。現時点では添付作品から確認できる `COSMO EFFECTS — Unity VFX Study` を主要項目とし、元画像そのものは表示しない。カード内のビジュアルはCSSとCanvasによる抽象的な生成プレビューにする。

未確認の制作実績は追加しない。今後の作品を追加しやすいよう、タイトル、種別、制作年、使用技術、説明を同じHTML構造で持たせる。

### Contact / `contact.html`

短い案内文、メール、GitHub、X、noteのみを表示する。問い合わせフォームや「依頼受付中」など、現在の状況を断定する文言は置かない。

メールリンクは `mailto:leftorenia@gmail.com` とし、外部リンクには適切な `rel` 属性と分かりやすいラベルを付ける。

## Components and file organization

- `assets/css/style.css` — 色、タイポグラフィ、共通レイアウト、各ページ、レスポンシブ、低モーション設定を集約する。
- `assets/js/cosmic-field.js` — 共通背景Canvasの生成とライフサイクルだけを担当する。
- `assets/js/work-preview.js` — Works内の小さな生成プレビューだけを担当する。
- `index.html`、`works.html`、`contact.html` — セマンティックなページ本文を持つ。
- `about.html` — 旧リンクからProfileへ案内する互換ページとする。

ライブラリやCDNは追加しない。外部フォントにも依存せず、端末の標準フォントスタックで成立させる。

## Accessibility and resilience

- 色だけで現在地やリンク状態を伝えない。
- キーボードフォーカスを常に視認できるようにする。
- 装飾Canvasは `aria-hidden="true"` とし、本文の前面に来ないようにする。
- 主要テキストと背景は十分なコントラストを確保する。
- JavaScriptが無効でも、ナビゲーションと全本文を利用できる。
- Canvasのピクセル比に上限を設け、非表示タブでは描画を止め、モバイルでは粒子数を減らす。

## Verification

- 3つの主要ページと旧About URLのリンクを確認する。
- HTMLの主要構造、ページタイトル、外部リンク、メールリンクを自動チェックする。
- デスクトップ幅とスマートフォン幅で各ページを表示し、重なり、横スクロール、可読性を確認する。
- 通常モーションと `prefers-reduced-motion` の双方を確認する。
- ブラウザコンソールにエラーがないことを確認する。
- 添付された `Cosmo_effects.png` やその派生画像がリポジトリへ追加されていないことを確認する。
